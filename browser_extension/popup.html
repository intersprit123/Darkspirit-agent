Darkspirit Agent

Connects the local Darkspirit companion to Gemini. Shift+S starts voice capture; Gemini replies are spoken using Chrome's default voice. Speech recognition runs locally.

Ready to test the local bridge.

Run start_gemini_voice.bat from the project folder. Press Shift+S to start listening, pause five seconds to submit, or press Shift+S again to submit early. Shift+Esc exits the background listener. Voice does not enable computer actions.
